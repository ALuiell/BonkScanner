# Map Marker Icons

Prototype assets for the optional full-map activity marker overlay.

- `pictograms/` contains recognisable activity glyphs.
- `shapes/` contains the alternate geometry-only set.
- Every SVG uses a transparent `32 x 32` canvas. Most glyphs use `#F5F7FA`;
  light marker fills use dark variants, while Egg and Sus Bush retain their
  identifying colors.
- Rarity is intentionally not baked into the glyph. The overlay should draw a
  separate white, blue, purple, or gold marker ring for Microwave and Shady Guy.
