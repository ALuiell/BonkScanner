# UI mockups

Design explorations are grouped by the part of the application they describe:

- `app_shell/` — main-window chrome, logs, and support controls.
- `build_progression/` — build-progression overlay variants.
- `design_system/` — broad redesign and button-system references.
- `player_stats/` — Live Stats, recordings, sessions, and run comparison.
- `streaming_tools/` — streaming layout and tracked-item configuration.

`bonkscanner_redesign.qss` stays at the root because it is a runtime asset used
by the application, development runner, build script, and stylesheet tests.
